## Overview

Resume Parser with RAG is an intelligent screening tool that combines retrieval-augmented generation with an LLM-powered conversational interface.

## Key Features

- Resume parsing and contextual retrieval with LangChain and FAISS
- Conversational interaction for faster candidate screening
- Reduced manual screening time by up to 85%

## Tech Stack

Python, Streamlit, LangChain, and FAISS.
