## Overview

Predo analyzes attendance data and forecasts future trends through a user-friendly Streamlit interface.

## Key Features

- Statistical analysis across 10+ attendance records
- Five or more Matplotlib visualizations for attendance patterns
- Interactive forecasts for semester planning and attendance management

## Tech Stack

Python, Streamlit, Pandas, and Matplotlib.
