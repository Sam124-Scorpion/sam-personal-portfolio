## Overview

Daily Expense Manager is a full-stack personal finance application that helps users manage and monitor their spending with AI-powered financial insights.

## Key Features

- Expense categorization across 10+ spending categories
- AI-driven budget recommendations based on spending patterns
- React.js frontend with a Django backend and SQLite3 database
